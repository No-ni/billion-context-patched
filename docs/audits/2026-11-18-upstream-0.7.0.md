## 独立复查与修复

独立只读复查核实了上游 build-info、当前包版本、旧来源维护记录，以及最终候选中 B18 与 IMG-10/11 的补丁存在。发现宿主占位恢复器允许任意 `sha256` 后缀，单靠已知摘要可能把用户的相似文本误当宿主占位。已收紧为两个已验证的宿主占位格式，并在 `scripts/check-host-image-fallback.mjs` 增加“已知摘要 + 用户自拟相似格式仍保持原文”的回归；原宿主格式、未知/歧义 hash、失败回执和消息外字段的保护用例仍保留。候选重建和完整检查须再次确认该修复进入最终产物。

上游新增 `isAudioOutputCall` 改变了请求用途分类依赖；`scripts/check-preflight.mjs` 已提取该实际函数及 `SERVER_EXECUTED_TOOL_TYPES`，并补充 TTS side request 与工具调用反例，避免旧检查因依赖遗漏而误判。
